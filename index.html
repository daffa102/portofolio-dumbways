Saya mulai ngoding web tahun 2024, lalu merambah ke IoT dan otomasi.

Saya Daffa, asal Bukittinggi, Sumatera Barat. Sejak mulai ngoding di tahun 2024, saya belajar membangun website dari dasar, sampai sekarang terbiasa memakai Laravel dan Livewire.

Ketertarikan ke IoT muncul setelah saya ikut pelatihan di ID-Networkers. Lalu di kampus saya kenal n8n, dan sejak itu saya senang membuat workflow otomasi: pekerjaan berulang yang bisa jalan sendiri.

Sekarang saya kuliah di prodi Teknologi Rekayasa Perangkat Lunak (TRPL) Politeknik IDN Bogor dan magang sebagai fullstack developer di Sultan TV. Salah satu tugas saya di sana adalah membangun landing page company profile untuk CV Akar, produsen air minum lokal.
